# TPI — Organización Empresarial

**Proyecto:** NexoSoft Soluciones SRL — Módulo Unificado de Tickets y SLA.

**Autor:** Gonzalo Gabriel Mayorga. Trabajo individual.

Este repositorio reúne la documentación académica de una organización ficticia y la propuesta de un módulo de gestión de tickets: registro, clasificación, asignación, trazabilidad y control de acuerdos de nivel de servicio (SLA). La planificación y los indicadores describen un sistema propuesto; no acreditan una implementación en producción.

## Declaración de uso de inteligencia artificial

Se utilizó **ChatGPT** para organizar y consolidar las entregas académicas, redactar y estructurar historias de usuario, definir indicadores coherentes con el proyecto y generar el modelo BPMN a partir del proceso de gestión de tickets. Se utilizó **Codex** para revisar la coherencia documental, identificar información incompleta, corregir y validar técnicamente el BPMN, regenerar sus exportaciones y preparar los archivos del repositorio.

Las solicitudes se describen por su finalidad en el [registro de evidencias](docs/evidencias/registro-colaboracion.md); no se presentan como transcripciones literales de prompts. La comprobación técnica asistida se distingue de la revisión humana. Las correcciones técnicas de esta revisión fueron realizadas con Codex; no se atribuyen como correcciones humanas ni como una validación manual completa del modelo BPMN.

La asistencia de IA no sustituye la responsabilidad del estudiante sobre la revisión conceptual, la exactitud del modelo y la documentación definitiva. Las metas propuestas no constituyen resultados medidos y las evidencias aún no disponibles se identifican expresamente.
